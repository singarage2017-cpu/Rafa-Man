# Rafa-Man para Android

Juego adaptado para teléfonos Android. Incluye controles táctiles, gestos de deslizamiento, sonido retro y pantalla completa.

## Generar el APK

Con Android Studio, abra esta carpeta y elija **Build > Build APK(s)**.
También se incluye una acción de GitHub que genera automáticamente `app-debug.apk`.

Requisitos: Android 6.0 o superior.
